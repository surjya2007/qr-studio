
# QR Studio

**Create. Customize. Download.**

QR Studio is a free, modern and easy-to-use QR code generator. Generate QR codes for websites, text, Wi-Fi networks, contact details and more.

## ✨ Features

- 🌐 Website URL to QR Code
- 📝 Text to QR Code
- 📶 Wi-Fi QR Code
- 👤 Contact QR Code
- 📧 Email QR Code
- 📱 Phone Number QR Code
- 🎨 Customize QR colors
- 🖼️ Add your own logo
- ⬇️ Download QR codes as PNG
- 📱 Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 Our Goal

To provide a simple, free and accessible QR code generator for everyone.
